# Agents and context engineering

Guides on building agents and feeding them the right context. All supplied 2026-10-23.

- [ ] **[A practical guide to building agents](https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf)** (OpenAI, PDF). Covers when to build an agent, design foundations and guardrails; a solid baseline for agent design.
- [ ] **[The Prompt Engineering Playbook for Programmers](https://addyo.substack.com/p/the-prompt-engineering-playbook-for)** (Addy Osmani). Practical prompting patterns for AI coding assistants.
- [ ] **[Best Practices for Building Agentic AI Systems: What Actually Works in Production](https://userjot.com/blog/best-practices-building-agentic-ai-systems)** (UserJot). Production patterns such as two-tier architecture and stateless design.
- [ ] **[A 7-part context engineering framework](https://www.reddit.com/r/ThinkingDeeplyAI/comments/1m2qspj/heres_a_7part_context_engineering_framework_that/)** (Reddit, r/ThinkingDeeplyAI). **Unverified:** the page could not be fetched; title inferred from the URL.
- [ ] **[AI agents don't need vector search anymore: inside the agentic search stack replacing RAG in 2026](https://buzzgrewal.medium.com/ai-agents-dont-need-vector-search-anymore-inside-the-agentic-search-stack-replacing-rag-in-2026-58efcabe4f6f)** (Abdullah Grewal, Medium). **Unverified:** the page returned no title or content; title inferred from the URL.
- [ ] **[Multiplayer AI will revolutionize the way we work](https://devinterrupted.substack.com/p/multiplayer-ai-will-revolutionize)** (Vincent Koc, OpenClaw Foundation). How multiple AI agents can collaborate in shared work sessions.
- [ ] **[Build Long-Running Agents](https://drive.google.com/file/d/18f4SUfj-_RqV2FXhnryOkJvzhMiUaHP-/view)** (based on Google Cloud's Agent Development Kit workshops, PDF). A six-layer architecture (trigger, runner, state, resumable workflow, human gate, guards) for agents that wait for days, survive a crash and never repeat a side effect.
